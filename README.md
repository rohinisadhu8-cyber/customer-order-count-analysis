# Excel Data Analysis – Sales, Profit & Top 10 Customers

## 📌 Project Overview
This project focuses on analyzing sales and profit data using Microsoft Excel. It helps identify top-selling products, top customers, and overall business performance through data analysis and visualization.

## 🎯 Objectives
- Analyze total sales and profit.
- Identify the top 10 products by sales.
- Identify the top 10 customers.
- Compare product performance.
- Create charts and PivotTables to visualize results.

## 🛠️ Tools Used
- Microsoft Excel
- CSV Dataset
- PivotTables
- Excel Charts

## 📂 Project Files
- `sales_dataset.csv` – Original sales dataset.
- `top_products.csv` – Top 10 products analysis.
- `top_customers.csv` – Top customer analysis.
- `sales_profit_analysis.xlsx` – Excel analysis and charts.

## 📊 Key Analysis
- Total Sales
- Total Profit
- Top 10 Products
- Top 10 Customers
- Sales and Profit Comparison

## 🚀 Steps Performed
1. Imported the sales dataset into Excel.
2. Checked and organized the data.
3. Created PivotTables for sales and profit analysis.
4. Sorted products and customers by sales.
5. Identified the top 10 products and customers.
6. Created charts to present the results.
7. Exported the analysis results as CSV files.

## 💡 Conclusion
This project demonstrates how Microsoft Excel can be used to analyze sales data, understand customer performance, identify profitable products, and support better business decisions.
